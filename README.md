## 🌴 VacationMax

A full-stack web application that helps users quickly determine whether their dream vacation is financially realistic — saving time and eliminating manual budget calculations.

## 🚀 Overview

VacationMax allows users to input different travel expenses and instantly get a clear evaluation of their budget. Instead of spending minutes calculating costs manually, users receive results in seconds with a simple and intuitive interface.

## ✨ Features
- Analyze total vacation expenses across multiple categories
- Instant budget evaluation (Affordable / Tight / Not Affordable)
- Smart classification system based on a 10% financial gap
- Real-time calculations via RESTful API
- Responsive and user-friendly UI


## 🛠️ Tech Stack
- Frontend: React, HTML, CSS
- Backend: Spring Boot (Java)
- API: RESTful services
- Tools: Git

## 📊 How It Works
- Enter your planned vacation expenses
- The backend processes the data
- The app calculates your total budget
- You get a clear financial status instantly

⏱️ Reduces calculation time from ~4 minutes to ~25 seconds

## 🎯 Purpose

This project was built to simplify travel planning and demonstrate full-stack development skills, including API design, data processing, and responsive UI development.
